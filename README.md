## Purpose

A command line quiz app to help you master distributed systems and prepare for the system design interview.

The quiz content is inspired from the popular [system-design-primer](https://github.com/donnemartin/system-design-primer) repository. The [system-design-primer](https://github.com/donnemartin/system-design-primer) repository is a great starting place for learning the basics of system design and the concepts that surround large scale distributed systems. This system_design_quiz app intends to serve as a companion to the [system-design-primer](https://github.com/donnemartin/system-design-primer) repository, enabling you to test your knowledge and gain valuable feedback.
